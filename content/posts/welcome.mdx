# 欢迎来到我的博客！

这是我个人博客的第一篇文章。在这里，我将分享：

- 🚀 最新的项目进展
- 💡 技术文章与教程
- 🎨 设计理念与实践
- 🔧 工程经验总结

## 网站功能

这个博客包含以下功能：

1. **文章与项目展示** - 通过 MDX 格式撰写，支持 Markdown 和 React 组件
2. **评论系统** - 访客可以在文章下方发表评论（无需注册）
3. **AI 生图工具** - 登录后可使用基于 ComfyUI 的生图功能
4. **响应式设计** - 完全适配移动端与桌面端
5. **深浅色主题** - 自动切换系统主题，也可手动切换

## 技术栈

- **前端框架**: Next.js 14 + React
- **样式**: Tailwind CSS
- **认证 & 数据**: Supabase (Auth + Postgres + Storage)
- **托管**: Vercel
- **内容**: MDX / Markdown
